## 1. Что было сломано (root causes, по фактам)

| # | Дефект | Где | Эффект для игрока |

| 1 | Смешаны offset и axial: `neighbors()` — offset-таблицы (с перевёрнутой диагональю), `distance()`/`hasLos()` — cube по тем же q,r | `model.ts` | 140 пар «не соседей» давали ближнюю атаку, 140 настоящих соседей — нет; движение по зеркальной сетке; ИИ промахивался мимо цели |
| 2 | `count` уменьшался на `ceil(урон/прочность)` и стеки убивались при `count === 0` | `attack/overwatch/ability` | юнит «уничтожен» при 20–66% HP (в probe: 9706/48360 и т. п.) |
| 3 | В v2 `counterUsed` не сбрасывался (сброс был только в `startV2`) | `v2EndPhase` | ответный удар — 1 раз за весь бой, дальше безнаказанные атаки → «односторонний бой» |

| 6 | Первая сторона раунда всегда игрок, чередования не было | `startV2/v2EndPhase` | первый ход = расход AP на сближение → систематический проигрыш авто-боя (0/60) |
| 7 | Авто-бой — отдельный «штрафной» цикл с манхэттенским соседством; у врага сдвинутый (более сильный) набор классов и «клин» | `overlay.doAutoBattle`, `createMockBattle` | перекос авто-боя; «всегда проигрываю» |

| 9 | Гонка таймера фазы ИИ: старый таймер затирал свежее состояние | `useEffect [screen, battle]` + `clone(battle)` в замыкании | «фальшивая победа» / откат состояния на экране итога |

## 3. Как проверить руками

1. `start-game.cmd` (или `node apps/web/node_modules/vite/bin/vite.js --port 5173`), Настройки → флаг сетки боя включён.
2. Любой бой → «Сетка командования» → «Авто» → «В бой ▶».
3. Нажать «ЗАВЕРШИТЬ ХОД»: при остатке AP кнопка станет «ПОДТВЕРДИТЬ ХОД» (+подсказка), второй клик → баннер «ФАЗА ПРОТИВНИКА», заголовок «ХОД ПРОТИВНИКА», в журнале атаки «Враг: …», HP в отряде падает; через ~0.8–1.5 с снова «ВАША ФАЗА · Раунд N».
4. «Авто-бой» на 8–12 сидах — примерно 50/50 (не 0/100).
5. Юниты не должны показывать «уничтожен» при заполненной полосе HP.

## 5. Открытые пункты (не блокируют, из ревизии docs/battle-v2-review-after-fix.md)

1. **Чередование первого хода (16b §1.3)**: если игрок закрыл вторую фазу раунда, следующий раунд открывает он → фаза ИИ наступает не после каждого клика. Сейчас это объясняет баннер «ВАША ФАЗА · Раунд N+1» + подсказка. Если приёмка требует фазу врага после каждого клика — это продуктовое решение, а не баг.
2. Паритет ±10% по 16b §8.6 достигается не всегда (нет отступления/«покинул бой»): сейчас победа = аннигиляция/капитуляция; `parity` считается по среднему двух сторон, а не по каждой.
3. Не перенесены в AP: 3 AP элиты/флагмана, адмиральские способности (16b §2.1/§2.5/§7.3); нет sudden death с раунда 16 и капа 1.5×MP за фазу.
4. Мёртвый код v1 (`GridBattleOverlay.tsx`, `adapter.ts`, v1-`endTurn/advanceTurn/nextRound/aiTurn/autoBattle`) — пометить deprecated или удалить; `packages/battle-grid` (полноценный движок) UI не использует — потенциальная задача «перевести UI на движок».
5. Скрытый +15% melee-бонус в `preview()` вне 15a §6.1; градаций сложности ИИ нет.
