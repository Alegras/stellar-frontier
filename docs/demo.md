# Демо-сценарий (3 минуты)

Цель: за 3 минуты показать все столпы гибрида — «одна империя, один корабль», читаемую экономику, живой мир и пиксельный полёт.

| Время | Действие | Что должно быть видно |
|---|---|---|
| 0:00 | Запуск `pnpm dev`, «Новая кампания» | Карта 240 систем, столица в центре, метки империй, гиперлинии |
| 0:20 | Клик по столице | Инспектор: звезда, планеты, станция, флот; кнопка «Войти в систему» |
| 0:30 | «Войти в систему» | 3D-система: звезда, планеты, станция; HUD полёта; «тактическая пауза» |
| 0:50 | `W`, мышь, `C` (суперкруиз) | Ускорение, гравитационный колодец, скорость в c, приближение к станции |
| 1:20 | `G` у станции | Экран станции: рынок, контракты, верфь, ремонт |
| 1:40 | Купить/продать ресурс, взять контракт | Кредиты и запасы меняются; контракт в списке |
| 1:55 | Отстыковка, `M` — на карту | Возврат без загрузки; метки флотов |
| 2:05 | `2` (скорость), открыть колонию | Попы, районы, дефицит/излишек, тултип формулы дохода |
| 2:30 | Наука: выбрать из 3 альтернатив | Прогресс школы, эффект выбора |
| 2:45 | Отправить флот в соседнюю систему с пиратами | Приказ, путь по гиперлиниям, отчёт автобоя или личный бой |

## Проверка «не фальшь»
- `pnpm test` — зелёный.
- `pnpm typecheck` — 0 ошибок.
- Опыт: «карта → полёт → станция → карта» суммарно ≤ 2 с переходов (без экранов загрузки).
- Детерминизм: `pnpm test` golden-тест 1000 тактов.
