# ADR-0005: Одна игра — режимы как конфигурации

Дата: 2026-11-04 · Статус: принято

## Контекст
Канон §IX-b требует единый ruleset и запрещает mode-специфичные ветки в системах.

## Решение
`packages/data/src/mode.json` (`ModeConfig`) задаёт: размер галактики, число ИИ, скорости, политику паузы, условия победы, сложность, стартовые условия. SP запускает локальный экземпляр того же кода симуляции. Режимы (кампания/песочница/испытание) — разные `ModeConfig`; `if (mode === ...)` в системах симуляции не используется.

## Последствия
+ Добавление режима = новый JSON + экран выбора, без форка баланса.
+ Тест паритета SP vs dedicated появится вместе с сетевым слоем (M11).
− В срезе доступен только режим кампании; конфиги песочницы/испытаний — задел.
