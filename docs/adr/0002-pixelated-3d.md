# ADR-0002: Рендер «pixelated 3D»

Дата: 2026-11-04 · Статус: принято

## Контекст
Требуется пиксель-арт, но с 6DOF-полётом (проекция требует объёма и глубины). Варианты: чистый 2D-пиксель-арт (теряет Elite-ощущение), пиксельные текстуры на 3D (дорого), pixelated 3D (дешёво и сохраняет полёт).

## Решение
`PixelPipeline`: Three.js рендерит сцену в RenderTarget 640×360 → пост-пасс (дизеринг Bayer 4×4, квантование в палитру ≤ 32 цветов, контур по depth-текстуре) → nearest-апскейл целым множителем с letterbox. UI — отдельный native DOM-слой с целочисленным масштабом.

## Последствия
+ 60 FPS на встроенной графике, нет текстур и UV, стиль задаётся кодом.
+ Переключение на «clean 3D» — параметр (internal resolution/palette=off), без переписывания.
− Мелкий текст в 3D нечитаем: подписи и HUD рисуются в DOM (native), 3D-объекты — только силуэты.
− Контур по глубине работает только на границах; для читаемости корабли используют контрастные vertex colors.
