# ADR-0004: Контент в JSON, целочисленная экономика

Дата: 2026-11-04 · Статус: принято

## Контекст
Нужно, чтобы баланс правился без пересборки логики, а одинаковый seed давал бит-в-бит одинаковое состояние (golden-тест, реплеи, будущий MP).

## Решение
- Все числа контента (стоимости, выходы, урон, цены, апкип, скорость флотов) — в `packages/data/src/*.json`, схема — `schema.ts`, валидация — zod (`pnpm data:validate`).
- Ресурсы империи — целые единицы; дробные доходы (например 4.5 минерала) накапливаются в `empire.frac` в тысячных долях и «вызревают» в целые единицы — без float в балансе.
- Наука: очки целые, остаток — в `frac`.
- Бой: FP и потери считаются от целочисленных статов; авторезолв использует детерминированный hash для дисперсии ±10%.

## Последствия
+ Детерминизм проверяется golden-тестом (seed + N тактов → одинаковый JSON).
+ Дизайнер/балансировщик правит только JSON.
− Дробные множители реализуются как проценты в целых (базис 1000); тултипы обязаны раскрывать формулу.
