# STELLAR FRONTIER

Браузерная космическая **4X-стратегия × космосимулятор от первого лица**: макроуровень школы Stellaris (империя, экономика, наука, традиции, дипломатия, войны, федерации, совет, шпионаж) + микроуровень школы Elite Dangerous (6DOF-полёт, суперкруиз, FSD, станции, бой). Это **полная игра по мастер-промту** `game-prompt/`: M0–M12 — от фундамента и галактики до кампании в 5 актов, кризисов, 6 условий победы, мегаструктур и кооператива/MMO через авторитетный сервер.

Статус приёмки **v0.6.1: M0–M12 + Часть XIII (M9c) + DLC XIV «Первый Свет» (M9d-0) — PASS**, открытых блокеров нет — `docs/acceptance.md` §21–23. Полный аудит 1000×7200 (3000 партий), MMO-hardening (PostgreSQL/Redis, HMAC, 300 CCU), конструктор, живой L2-бой, Древние/расы/Предел, DLC-квесты/диалоги/журнал/дерево, доступность и CI. **Русский — основной и обязательный язык; EN — опциональный переключатель.**

Один ruleset, один контент, один HUD, одна схема сейва: одиночная кампания запускает тот же серверный код локально (канон Части IX-b).

## Быстрый старт

**Самый простой способ (Windows):** двойной клик по `start-game.cmd` в папке проекта — поднимется Vite и откроется браузер на `http://127.0.0.1:5173/`. Окно с сервером должно оставаться открытым; Ctrl+C — остановить. Альтернатива: правый клик по `start-game.ps1` → «Выполнить с помощью PowerShell».

**Через терминал** (PowerShell / Windows Terminal / VS Code):
```bash
cd stellar-frontier
pnpm install
pnpm dev          # открой http://127.0.0.1:5173
```

Если `pnpm` не установлен глобально, используйте бандл-исполнение:
`node <путь-к-pnpm.mjs> install` и `node <путь-к-pnpm.mjs> -C apps/web dev` (в этой среде: `C:\Users\vawum\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\pnpm\bin\pnpm.mjs`, Node: `...\dependencies\node\bin\node.exe`).

Проверки:

```bash
pnpm typecheck    # tsc strict, без ошибок
pnpm test         # Vitest: детерминизм, галактика, экономика, команды, бой, save/load
pnpm data:validate# zod-валидация контента packages/data
pnpm build        # production-сборка (бюджет стартового бандла)
```

## Управление

### Карта (L0)
| Действие | Ввод |
|---|---|
| Панорама / зум | ЛКМ-перетаскивание / колесо |
| Выбрать систему | ЛКМ по системе или метке |
| Войти в систему | Двойной клик / кнопка «Войти в систему» |
| Выбрать флот | Клик по фишке флота |
| Скорость такта | `1` `2` `3` `5`, пауза — `Space` |
| Скорость 0 | `0` |
| Помощь | `F1` или кнопка «?» |

### Полёт (L1) и бой (L2)
| Действие | Ввод |
|---|---|
| Тяга 0–100% | `W` / `S` |
| Тангаж / рыскание | Мышь (клик — захват курсора) |
| Крен | `A` / `D` |
| Форсаж | `Shift` |
| Assist on/off | `Z` |
| Стоп | `X` |
| Суперкруиз | `C` |
| FSD-прыжок к соседней системе | `Tab` (выбор) + `J` |
| Пипсы SYS/ENG/WEP | Стрелки |
| Огонь: лазеры / кинетика | ЛКМ / ПКМ |
| Выбрать цель | `Q` |
| Сброс тепла | `V` |
| Стыковка (у станции) | `G` или касание станции на скорости < 800 м/с — автостыковка |
| На карту | `M` / `Esc` |

Столкновения: звезда — гибель корабля (капсула, возврат на карту), планеты/астероиды/станция — выталкивание и урон по щиту→броне→корпусу (одно столкновение не убивает флагман). Вражеские корабли также расталкиваются и получают урон.

## Архитектура

```
apps/web                 React 19 + Vite + Three.js
  src/game               стор (Game), селекторы, сохранения (IndexedDB)
  src/render             PixelPipeline, SceneHost, GalaxyView, SystemView (полёт)
  src/ui                 HUD, панели, метки карты, станция, оверлеи
packages/sim             чистая детерминированная симуляция (без DOM)
  src/types.ts           контракт World/Command/API
  src/galaxy.ts          генератор галактики (seed)
  src/economy.ts         производство/потребление/дефициты (целочисленно)
  src/tick.ts            12 фаз такта = 1 игровые сутки
  src/commands.ts        команды игрока (валидируются)
  src/combat.ts          авторезолв по FleetPower (GDD §11.6)
  src/ai.ts              ИИ-империи
  src/save.ts            сериализация (round-trip идентичен)
packages/data            весь баланс и контент в JSON + zod-валидация
docs/                    ADR, демо-сценарий, приёмка
```

Ключевые инварианты:

- **Детерминизм**: нет `Math.random`/`Date.now` в `packages/sim`, PRNG только через `prng.ts`, экономика — целочисленная с милли-остатками, порядок фаз фиксирован.
- **Баланс — только в данных**: числа в `packages/data/*.json`, не в коде.
- **Один мир для всех режимов**: `mode.json` — единственное место, где режимы различаются (скорости, пауза, лимиты).

## Демо на 3 минуты

1. В меню выберите режим: «Новая кампания» (или песочница/испытание; кооп/MMO — через «Сеть») → на карте 240 звёзд, у столицы уже есть флот.
2. Выберите столицу → панель «Войти в систему» → вы в 6DOF-полёте (такт заморожен — тактическая пауза).
3. Держите `W`, поверните мышью, включите `C` (суперкруиз) и долетите до станции; `G` — стыковка → рынок, контракты, верфь.
4. Отстыкуйтесь, `M` — обратно на карту; `1` — время пошло; стройте районы, исследуйте технологии, отправляйте флоты.
5. Пираты в соседней системе: войдите и уничтожьте их лично или отправьте флот и получите отчёт авторезолва.

## Полная игра и мультиплеер (M6–M12)

- **Режимы:** кампания (SP), кооп 2–4, MMO-сезон 30–100 — конфигурации одного ядра @sf/sim (MODES в @sf/data).
- **Мультиплеер:** `node <runtime>/pnpm.mjs api` поднимает авторитетный сервер (Fastify+WS, порт 8787). В клиенте — кнопка «Сеть» или `?lobby=1&mpApi=http://127.0.0.1:8787`; лобби по коду, пауза-голосование, тактический лок, реконнект 30 с, чат.
- **Тесты MP:** `node <runtime>/pnpm.mjs mp-test` (2 WS-клиента); e2e — `apps/web/e2e/mp.spec.ts` (2 браузера).
- **Протокол:** docs/mp-protocol.md. Снапшоты JSON; комнаты/игроки/мир персистятся в PostgreSQL/Redis (или durable JSON-файл в dev), восстановление после рестарта — §10.
- **Кооп = shared empire:** все места управляют одной империей (victory по playerEmpireId); MMO — отдельные империи на место (сезонный рейтинг — серверный, вне sim).
- **Политическая карта:** панель рядом с миникартой — цвета империй, границы, легенда с числом систем, клик по системе/легенде; сворачивается.
- **Случайные события:** модалка события ставит время на паузу до выбора; «Отложить» убирает событие из очереди (без накопления).
- **Язык:** русский — основной и обязательный (контент, интерфейс, ошибки). EN — опциональный переключатель в настройках (перевод данных + chrome, без перезагрузки).
